## 🤖 AI Developer Assistant

AI 기반 개발 학습 지원 및 코드 분석 시스템입니다.

코드 에러 분석, 학습 기록 저장, 출석 체크, 성장 그래프 시각화를 하나의 흐름으로 연결하여  
개발 학습 과정을 관리할 수 있도록 구현한 개인 프로젝트입니다.

FastAPI 기반 백엔드 서버와 SQLite 데이터베이스를 사용했으며,  
Ollama 로컬 AI 환경을 연동하여 AI 분석 기능을 구성했습니다.

또한 Docker와 AWS EC2 환경을 활용해 서버 배포 및 운영 경험도 함께 진행했습니다.

### Main Features

- 코드 에러 AI 분석
- 분석 결과 저장
- 학습 기록 관리
- 출석 체크 시스템
- 성장 그래프 시각화
- FastAPI 기반 API 서버
- SQLite 기반 데이터 저장
- Docker 기반 실행 환경 구성
- AWS EC2 서버 배포 경험

### Tech Stack

- Python
- FastAPI
- SQLite
- HTML
- CSS
- JavaScript
- Chart.js
- Ollama
- Docker
- AWS EC2

## 🚨 AI CCTV Behavior & Danger Detection System

실시간 CCTV 환경을 기반으로 한 AI 이상행동 감지 및 위험물체 탐지 팀 프로젝트입니다.

MediaPipe Pose와 LSTM 기반 행동 분석을 통해 이상행동을 감지하고,  
YOLO 기반 객체 탐지를 통해 위험물체를 탐지합니다.

분석 결과를 바탕으로 위험도 점수를 계산하고,  
Discord 위험 알림, 관리자 대시보드, RAG 기반 대응 가이드까지 연결한  
AI 기반 통합 관제 시스템입니다.

이 프로젝트는 Docker와 Render를 활용해 실제 배포까지 완료했습니다.

### Main Features

- 영상 업로드 및 분석
- 실시간 CCTV 웹캠 감지
- MediaPipe Pose 기반 행동 분석
- LSTM 기반 이상행동 감지
- YOLO 기반 위험물체 탐지
- 위험도 점수 계산
- 자동 대응 시스템
- Discord 위험 알림
- 관리자 대시보드
- 분석 기록 저장 및 조회
- RAG 기반 대응 가이드
- Docker + Render 기반 배포

### Tech Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite
- PyTorch
- YOLO
- OpenCV
- MediaPipe
- LSTM
- HTML
- CSS
- JavaScript
- Chart.js
- Discord Webhook
- RAG
- Docker
- Render
